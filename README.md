# hello-agent

A simple web application in Go that displays "Hello Atlassian from Github Copilot".

## Requirements

- Go 1.24.13 or later

## Running the Application

To run the web application:

```bash
go run main.go
```

The server will start on port 8080. Visit http://localhost:8080 in your browser to see the message.

## Building

To build the executable:

```bash
go build -o hello-agent main.go
```

Then run the executable:

```bash
./hello-agent
```
