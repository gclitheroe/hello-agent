# hello-agent

A simple web application that displays "Hello Atlassian from Github Copilot" in large font.

## Requirements

- Go 1.24.13 or later

## Running the Application

To run the application:

```bash
go run main.go
```

Or build and run:

```bash
go build -o hello-app main.go
./hello-app
```

The server will start on port 8080. Open your browser and navigate to `http://localhost:8080` to see the greeting message.
