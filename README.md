# hello-agent

A simple Golang web application that displays "Hello EngFest #5 from Github Copilot" in large font.

## Requirements

- Go 1.21 or higher

## How to Run

1. Build the application:
   ```bash
   go build -o hello-agent
   ```

2. Run the application:
   ```bash
   ./hello-agent
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:8080
   ```

## Features

- Written in Go using only the standard library
- Displays "Hello EngFest #5 from Github Copilot" in large, centered text
- Responsive web design
