# Hello Atlassian Webapp

A simple Go web application that displays "Hello Atlassian from Cursor Cloud Agents" in large blue font.

## Run

```bash
go run main.go
```

The server starts on port **8080**. Open [http://localhost:8080](http://localhost:8080) in a browser.

## Build

```bash
go build -o hello-atlassian .
./hello-atlassian
```
